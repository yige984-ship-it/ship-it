# Xiuxian AI Studio

手机友好的修仙国漫制作工作台，FastAPI + SQLite + 原生响应式 Web + FFmpeg。第一阶段为可运行的本地 MVP，全流程不调用收费 API。

## 本地启动

需要 Python 3.11+、FFmpeg/ffprobe（含 libx264、drawtext），推荐 Linux。Ubuntu 可由管理员安装 `ffmpeg python3-venv`。

```bash
cp .env.example .env
./scripts/start.sh
```

访问 http://127.0.0.1:8000 ，接口文档为 `/docs`。停止后项目保存在 `data/`，浏览器恢复最近一次项目。启动脚本创建虚拟环境并安装锁定的直接依赖。

```bash
./scripts/test.sh
```

测试包含实际 120 秒竖屏 MP4 合成与 ffprobe 音视频轨道、时长检查，通常需数十秒。测试项目使用临时目录。

## 第一阶段行为与边界

1. 输入中文文本（最多20,000字、请求体100KB），按句子顺序分配到12个10秒镜头；不足处插入空镜。旁白保留原文，长文不保证120秒内可读完，需人工缩写。
2. 生成JSON草案、默认主角档案、每镜提示词、镜头图像/视频/配音任务、每镜估算与整体预算。角色不是自动语义识别结果，剧本不是大模型改编。
3. 9个关键帧镜头、3个低动作镜头作为成本规划策略。模拟渲染复用同一色卡，逐镜输出测试片段，再合成竖屏360×640、12fps、120秒H.264/AAC MP4。
4. 图像、视频、配音经独立适配器调用；模拟图像是色卡，视频含英文SIMULATION水印，音频为静音。`completed_mock`仅表示模拟合成完成，绝不表示真实AI影片完成。
5. SQLite保存计划、任务进展、错误、尝试次数。失败可在额度内重新合成整个项目，重启将中断任务改为失败。可下载分镜JSON和模拟MP4。

## 价格与预算

`config/pricing.json`仅是可维护的规划示例，不是任何供应商实时报价。上线前根据选定供应商价格修改并标明来源、日期。每项目保存创建时的价格快照。

关键帧镜头按一张图估算，低动作镜头按秒估算，旁白按字数估算；各项向上保留两位小数，总计另加15%预留。模拟API实际支出为0；不包含服务器、电力、存储、流量。估算超过用户预算或服务器预算上限时禁止合成，最高150元。真实生成成本、质量与120秒可用成片不能由当前示例价格保证。

默认不自动提交任何收费任务，即使设置密钥也不会使用；`mode=real`或`PROVIDER_MODE`非mock会明确拒绝。MVP未实现供应商SDK，因此不需要API密钥。

## API

- `GET /api/health`：模式与收费调用关闭状态。
- `POST /api/projects`：`{"text":"小说正文","budget_cny":150}`。
- `GET /api/projects/{id}`：JSON、每镜任务状态、估价。
- `POST /api/projects/{id}/render`：`{"mode":"mock"}`，同步等待合成，可由其他请求轮询状态。
- `GET /api/projects/{id}/download`：只有模拟成功后可下载。

状态：`planned → rendering_mock → completed_mock | failed`；失败可重新合成。全项目生成次数默认最多3次，项目总量默认100。SQLite适用于本机单进程；当前锁与限额不能用于多进程分布式部署。

## 安全与部署前提

密钥只通过服务器环境变量配置，不能提交`.env`、放入浏览器或写入日志。仓库忽略`.env`、本地数据库、生成素材和虚拟环境。FFmpeg使用参数数组而非shell，素材文件名由服务器生成，不接受用户路径或远程URL。

MVP仅监听127.0.0.1，是单用户本地工具，无登录与租户隔离。不要直接暴露公网。外部部署需要TLS、登录/授权、每用户限流与存储清理、反向代理请求体和超时设置、持久化数据目录、日志轮转、磁盘额度、备份及依赖安全审计。项目ID不是权限机制。禁止上传文件；当前只接受受限JSON文本。
