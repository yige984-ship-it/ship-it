# 本地多镜头剪辑、字幕和声音

这一步无需注册新服务商，不调用模型API。输入是当前项目已保存到服务器的真实图片素材。
输出是360×640、12fps、H.264/AAC MP4，可在iPhone内联播放或下载，同时提供SRT和JSON时间轴。
这是带标识的本地关键帧动画，图片缩放/移动，不是人物动作视频或真实AI图生视频。

## 使用流程

1. 先生成图片并保存到项目；可以为多个不同镜头生成图片。
2. 在“本地剪辑：多镜头、字幕和声音”选择范围：
   - 已保存镜头片段：只拼接选中图片对应镜头，时长按方案镜头时长计算，不称为完整120秒。
   - 120秒整集：要求12个镜头都有当前版本图片。
3. 缺图时，默认停止并列出缺失镜头。只有勾选允许复用现有图片，才复用邻近镜头图片补足。
   复用不是新图片生成；界面和时间轴记录会标明reused_images和每镜reused。
4. 选择静音字幕，或离线机械中文声。Docker已安装eSpeak NG和中文字体，不需要新的API密钥。
5. 点击制作，后台执行，页面每3秒查询进度；完成后可播放/下载MP4、SRT和时间轴记录。
6. 免费实例可能休眠/重启丢失全部素材，请及时下载到手机。

## 声音的真实边界

- 离线中文声由eSpeak NG的cmn生成，声音机械，不保证多音字、专名、韵律和国漫表演效果。
- 不是自然人声或云端AI配音，不含音效和音乐。
- 静音模式保留静音AAC轨道；不能标记为配音成功。
- 有字镜头实际调用离线合成，无字镜头留静音；记录voiced_shots数量。
- 无配音程序、无旁白或旁白过长会明确拒绝/失败，不偷偷退回静音冒充配音。
- 原始语音长于镜头时仅允许最多1.3倍提速，超过则要求缩短旁白/调整时长。

## 字幕与合成

每镜按旁白字符分段，分配到镜头时间内，最多18字每行、2行；这不是强制语音对齐。
整镜超过每秒12字时拒绝，仍需人工审查阅读速度和语义断句。
字幕使用UTF-8 SRT，并烧录到视频中；转义用户HTML/ASS格式标记，不传入shell。
默认无转场、无背景音乐，防止假装自动生成完整声效或引入未经核实的音乐授权。
实际FFmpeg合成后，ffprobe校验时长及音视频轨道，再标记completed_local。

## API

- GET /api/local-production：离线能力和声音类型。
- POST /api/projects/{id}/episodes：revision、image_job_ids、scope(selected/episode)、allow_reuse、voice_mode(silent/offline_zh)。
- GET /api/projects/{id}/episodes：任务列表与制作进度。
- GET /api/episodes/{id}：单个任务。
- GET /api/episodes/{id}/preview：MP4内联播放，支持HTTP Range。
- GET /api/episodes/{id}/download：下载MP4。
- GET /api/episodes/{id}/subtitles：下载SRT。
- GET /api/episodes/{id}/manifest：下载时间轴及复用/声音记录。

任务状态queued→running→completed_local/failed。只接受当前项目当前方案版本已保存素材。
新编辑方案不修改已创建剪辑的快照，旧剪辑明确显示版本；不能当作新方案成片。
一次只运行一个本地剪辑，单项目默认最多10次，MAX_EPISODES可配置；可在失败后新建任务重做。
FastAPI BackgroundTasks是进程内后台任务，不是可靠队列；重启会将中断任务标为failed，不自动收费重试。
正式队列、逐镜恢复、持久化多进程锁及数据库连接管理仍需后续实现。
api_cost_cny=0仅指本地剪辑没有模型调用，不代表此前图片、服务器、存储和流量免费。

- 实际FFmpeg多镜头20秒拼接与120秒明确复用模式均通过时长和轨道检查。
- 字幕SRT、Range播放、缺图拦截、旧版本/跨项目/缺失素材拒绝及失败状态通过测试。
- Docker实际安装eSpeak NG/中文字体，断网容器中合成非静音机械中文WAV，并完成带字幕10秒H.264/AAC片段。
- 测试使用合成色彩图验证，不声称测试图片来自真实模型；真实图片复用已有用户验收入口。
- iPhone本阶段交互、离线发音效果及线上新版本部署仍需实际验收。
